# PR レビューコメント取得

## 概要

GitHub PR の URL を入力として受け取り、`gh` CLI を使ってレビューコメントを取得・構造化するワークフロー型スキル。

インラインコメント、PR 本体コメント、レビューサマリーの3種類を取得し、ファイル別・行番号順にグルーピングして出力する。特定のレビュー ID が指定されている場合はそのレビューのコメントのみに絞り込む。

### 用語

| 用語 | 説明 |
|------|------|
| **インラインコメント** | コードの特定行に対するレビューコメント |
| **PR コメント** | PR 全体に対する非インラインのコメント |
| **レビューサマリー** | レビュー提出時の総括コメント（approve/request changes 等） |
