# PR レビュー対応

## 概要

GitHub PR のレビューコメントを受け取り、体系的に分析・対応・検証・ルール化するワークフロー型スキル。

単発の修正ではなく、同様のコメントが再発しないようルール化まで行うことで、コードベースの品質を継続的に向上させる。

---

## ワークフロー概要

| Phase | 主体 | 内容 |
|-------|------|------|
| 1. コメント取得・分析 | 🤖 Claude 自動 | PR URL からコメントを取得し、種別と対応要否を分類 |
| 2. 質問への回答 | 🤖 Claude 自動 | 質問形式のコメントに回答を作成 |
| 3. 修正方針策定 | 🤖 Claude + 👤 ユーザー確認 | 修正方針を策定し、影響範囲を特定 |
| 4. フェーズ別修正 | 🤖 Claude 自動 | グループ化した修正を順次実施 |
| 5. 品質チェック | 🤖 Claude 自動 | fmt, clippy, test を実行 |
| 6. ルール化検討 | 🤖 Claude + 👤 ユーザー確認 | 汎用的なルールとして抽出可能か判断 |

## クイックスタート

### 1. PR URL を渡す

```
PR のレビューコメントに対応してください: https://github.com/owner/repo/pull/123
```

### 2. 特定レビューのみ対応

```
このレビューに対応してください: https://github.com/owner/repo/pull/123#pullrequestreview-456789
```

### 3. ルール化まで実施

```
PR レビュー対応後、ルールとして採用すべきものがあるか確認してください
```
