# docs/specs

実装された仕様（WHAT）と、その設計に至った意思決定の経緯・根拠（WHY）を記録する。

コードと同じブランチ・コミットに含まれるため、任意の過去コミットをチェックアウトすれば
その時点の正しい仕様を確認できる。開発管理（要件・タスク・議論・進捗）は GitHub Issues 側で行う。
